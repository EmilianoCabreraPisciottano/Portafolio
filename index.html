Sitio + backend

Clínica Colibri

Sitio institucional y sistema de contacto para una clínica interdisciplinaria, construido con HTML, Bootstrap, CSS y JavaScript en el frontend, más un backend Node/Express para recibir formularios, guardar envíos y notificar por email.

Implementa validación de formulario en cliente y servidor, acordeones accesibles, modales por servicio, galería responsive, mapa embebido, persistencia en JSON, envío con Nodemailer y rate limiting básico en el endpoint de contacto.

Qué resuelve

Presentación profesional de servicios, captación de consultas y almacenamiento simple de leads sin depender de una base externa.

HTML + Bootstrap Node/Express Nodemailer

App de negocio

MoveMood

Aplicación de entrenamiento y seguimiento desarrollada con Java 21 y Spring Boot, estructurada con capas de servicio, fachada, repositorios JPA y entidades de dominio para rutinas, usuarios, mesociclos y registros.

Incluye cálculo automático de pagos, asignación y edición de rutinas por día, historial de progreso, validaciones de negocio, endpoints protegidos y una interfaz web separada para cliente y entrenador con lógica JavaScript dedicada.

Qué resuelve

Gestión centralizada de entrenamientos, clientes, pagos y seguimiento de progreso con reglas de negocio claras.
